# Guia de uso — Painel MP

## 1. Abrir o painel

Abra `painel-horas-financeiro/index.html` em um navegador atualizado. O painel foi preparado para telas de computador e celular.

## 2. Horas trabalhadas

Na aba de horas, informe a empresa/turma, selecione os dias da semana, preencha os horários de início e fim e informe os parâmetros de remuneração e acompanhamento solicitados na tela. Salve o cadastro para que ele apareça na lista e nos resumos.

Confira os horários e os dias antes de salvar: o cálculo depende dos dados informados.

## 3. Financeiro

Registre cada entrada como receita ou cada saída como retirada, com valor, data e descrição. Selecione o mês para consultar os totais e use o relatório diário para conferir movimentações de uma data específica.

## 4. Aulas particulares

Informe aluno ou local, data, valor da hora, duração e os dados de deslocamento/combustível. O painel apresenta a estimativa do valor total e permite salvar a precificação.

## 5. Calculadora avulsa

Use a calculadora avulsa para simulações que não devem ser adicionadas aos registros salvos.

## 6. Backup e restauração

- **Baixar backup:** exporta os dados disponíveis em um arquivo JSON.
- **Restaurar backup:** selecione um arquivo JSON de backup. O painel mostra um resumo dos registros encontrados e pede uma segunda confirmação antes de restaurar.

Guarde cópias do backup fora do navegador. Limpar os dados do navegador pode apagar os registros locais.

## 7. Publicação

O código está em HTML único, com CSS e JavaScript incorporados. Pode ser hospedado como site estático. A integração de nuvem que depende de APIs do ambiente original não é garantida em hospedagem estática comum.
